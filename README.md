STORMDOCK is a round-based tactical FPS built on three.js: 5v5 matches against bots, a bomb to plant and defuse, money earned each round and spent in a buy menu, and gunplay where stopping to aim pays — played on an original night container-port map in a storm, with rain, floodlights and wet asphalt.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
